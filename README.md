# PROJECT SENTINEL

An early experiment in AI failure detection and human oversight.

## Question
When should an AI agent be allowed to continue, when should its
output be reviewed, when should a human step in, and when should
it be stopped?

## Decision levels
- GREEN - Allow
- YELLOW - Review
- ORANGE - Human intervention
- RED - Stop

## Status
v0.1 prototype. 10 customer-service test scenarios.
Gold labels written by me before checking any AI output.

## Background
Built by Lucentio Harris, 14 years in document QA, records
management and exception handling, moving into data annotation,
LLM evaluation and AI safety.

## Limitations
Small test set. Early labeling rules. Results are preliminary.
